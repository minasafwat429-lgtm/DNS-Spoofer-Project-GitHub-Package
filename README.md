DNS Spoofer

A Python-based educational DNS spoofing demonstration tool built using Scapy and NetfilterQueue.

This project intercepts DNS packets and demonstrates how DNS responses can be modified in controlled lab environments for cybersecurity learning and network security awareness.




## Installation
1. Clone Repository
   ```
    git clone https://github.com/YOUR_USERNAME/DNS-Spoofer.git
    cd DNS-Spoofer


3. Install Requirements
   ```
    pip install -r requirements.txt


5. Install Linux Dependency
 ``` Ubuntu / Kali Linux:
       sudo apt install libnetfilter-queue-dev
```

##Usage

Run the script:

```
sudo python3 dns_spoofer.py
```
